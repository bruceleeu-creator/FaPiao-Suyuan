## 四、必须完成的功能

### 1. 工程基础

- 使用 React + Vite + TypeScript。
- 应用能在本地启动。
- 保留电脑端优先布局。
- 预留手机端入口占位，但不开发完整手机端。

### 2. 页面入口

必须至少包含以下电脑端页面或视图：

1. 工作台首页。
2. 发票列表。
3. 单张发票三阶段处理页。
4. 异常工作台。
5. 风险驾驶舱。
6. 手机端入口占位页。

### 3. 首批演示数据

准备最小演示数据，至少包含：

- 餐饮费案例。
- 住宿费案例。
- 咨询服务费案例。
- 一个验真失败或重复发票案例。

### 4. 页面内容边界

页面要体现以下产品逻辑：

- 发票识别 -> 业务还原 -> 入账风险。
- 四类对象：发票、业务事件、证据链、风险决策。
- 四道闸门：发票、业务、证据、风险。
- 凭证草稿只是草稿，不自动过账。
- OCR、验真、凭证接口是模拟状态。
