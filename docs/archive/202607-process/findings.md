# CO_发票溯源证据链系统发现记录

## 项目定位

本项目不是单纯 OCR 发票识别工具，而是以发票为入口、以业务事件为核心、以证据链为基础、以财税风险决策为结果的智能入账系统。

核心链路：

发票提供线索 -> 业务事件还原事实 -> 证据链证明事实 -> 风险决策处理事实 -> 生成人工确认后的凭证草稿。

## 已落地产品骨架

- 发票识别：模拟 OCR、验真、查重、红冲、异常、候选场景和置信度。
- 业务还原：业务追问、事实结构化、证据补充、证据模板下载和矛盾识别。
- 入账风险：会计建议、税务判断、风险卡片、整改建议、凭证草稿和人工确认。
- 工作台：发票录入、列表、详情、流程处理、结果页、异常队列、风险驾驶舱、接口配置。
- 后端预留：腾讯云 OCR / 验真代理和标准凭证模板导出。

## 一期范围

一期覆盖八类高频发票：

1. 餐饮费
2. 住宿费
3. 交通出行费
4. 车辆相关费用
5. 办公用品
6. 咨询及服务费
7. 广告宣传及推广费
8. 租赁及物业费用

三类做深：餐饮、住宿、咨询服务。

## 暂缓范围

- 自动过账
- 自动申报
- 完整纳税申报表
- 复杂集团合并
- 全量银行流水系统
- 全量合同或采购系统
- 高风险事项无人审批
