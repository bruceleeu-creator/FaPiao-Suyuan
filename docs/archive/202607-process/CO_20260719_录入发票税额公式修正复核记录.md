## 公式复核结论

录入页应以用户最容易理解的“价税合计”作为输入，再自动拆分不含税金额和税额：

```text
不含税金额 = 价税合计 ÷ (1 + 税率)
税额 = 价税合计 - 不含税金额
```

官方依据：

- 国家税务总局口径：销售额 = 含税销售额 ÷（1 + 税率或征收率）；税额 = 含税总收入 - 销售额。
- 上海税务问答口径：采用销售额和销项税额合并定价时，销售额 = 含税销售额 ÷（1 + 税率）。
