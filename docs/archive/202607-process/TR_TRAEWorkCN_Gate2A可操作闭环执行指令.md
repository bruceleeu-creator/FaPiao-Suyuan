## 一、本轮目标

当前 Gate 1 只是展示型骨架。请将应用整改为“正常使用者可以从录入发票开始，一直到生成风险建议”的可操作闭环。

本轮必须跑通：

发票录入 -> 模拟 OCR -> 票面确认 -> AI 业务追问 -> 证据补充 -> AI 风险初判 -> 人工采纳/修改 -> 生成风险建议与凭证草稿。

## 四、必须完成的功能

### 1. 入口

- 首页和发票列表页必须出现明显按钮：`录入发票`。
- 新增路由：`/intake` 或 `/invoices/new`。
- 录入页支持：
  - 选择演示样例。
  - 手工填写基础票面字段。
  - 上传控件占位，明确 OCR 为模拟。
  - 点击 `开始识别` 后进入流程页。

### 2. 互动流程

新增流程页：`/invoices/:caseId/workflow`。

必须包含步骤条：

1. 发票输入。
2. 票面确认。
3. 业务追问。
4. 证据补充。
5. AI 风险初判。
6. 人工复核。
7. 生成建议。

每一步必须有按钮或表单动作，不能只展示文字。

### 3. AI 介入面板

新增 `AI 辅助判断面板`。

必须展示：

- 当前 AI 任务。
- 输入来源。
- AI 输出。
- 置信度。
- 追问问题。
- `采纳`、`修改`、`退回`动作。

AI 结果仍然使用 mock service，不调用真实模型。

### 4. 业务追问和证据补充

三类做深必须有不同追问模板：

- 餐饮：招待对象、参与人、业务目的、审批记录。
- 住宿：出差申请、行程、住宿人员、项目归属。
- 咨询服务：合同、服务内容、成果物、验收单、付款记录。

证据补充可以用复选框或模拟上传项实现。

### 5. 生成风险建议

新增结果页：`/invoices/:caseId/decision`。

点击 `生成风险建议` 后必须显示：

- 四道闸门结果。
- 会计处理建议。
- 增值税处理建议。
- 企业所得税处理建议。
- 其他风险提示。
- 证据链结论。
- 风险等级和置信度。
- 整改建议。
- 审批要求。
- 凭证草稿建议。
- 最终状态：可生成草稿 / 待人工确认 / 禁止生成 / 暂不能判断。

高风险、验真失败、疑似重复、证据缺失、低置信度案例不得输出“可直接生成凭证”的结果。

### 6. 操作日志

每次用户点击关键动作必须写入本地操作日志并在页面展示：

- 开始识别。
- 确认票面。
- 回答追问。
- 补充证据。
- 生成 AI 初判。
- 采纳 / 修改 / 退回。
- 生成风险建议。
