## 2. 首次发现的阻断项

### P1：前端密钥保存边界不合格

首次输出中，`IntegrationSettingsPage.tsx` 仍保留 `API Key / Token` 可编辑输入框，并通过 `config.apiKey` 进入 `localStorage` 保存路径。这与当前阶段“只预留腾讯云接口、不保存真实密钥、不调用真实服务”的边界冲突。

整改要求：

- 配置页不得提供 API Key / Token 输入框。
- 前端不得保存 SecretId、SecretKey、Token 或 API Key。
- 保存、读取、更新、测试连接返回值都必须强制清空 `apiKey`。
- 必须新增测试证明即便误传密钥，也不会落入 `localStorage`，旧脏数据也不会回流到 UI。

### P2：格式门禁不通过

首次输出中，`git diff --check` 报告 `src/styles.css` 文件末尾存在多余空行。
