## 四、必须完成的功能

### 1. 多发票会话

- 每次录入发票生成独立 `caseId`。
- 发票列表显示本地创建的多张发票。
- 每张发票有独立状态、日志、AI 介入记录、证据链和风险建议。
- 支持从列表继续处理某一张发票。
- 不再只依赖 `/invoices/current/...` 作为唯一流程。

### 2. 16 状态机

实现或固化 16 个状态：

`待识别`、`识别中`、`待确认票面`、`待还原业务`、`待回答问题`、`待补充证据`、`业务已还原`、`待风险判断`、`待财务复核`、`待负责人审批`、`待生成凭证`、`凭证草稿已生成`、`已完成`、`已退回`、`暂不能判断`、`已作废或已红冲`。

要求：

- 有合法流转表。
- 非法流转被拒绝。
- 每次状态变化写入操作日志。

### 3. localStorage 持久化

至少持久化：

- 多发票 case 列表
- 当前 active caseId
- 每个 case 的 workflow session
- 操作日志
- 风险建议结果

刷新页面后数据不丢失。

### 4. 异常工作台联动

异常工作台必须合并或读取本地 case 数据，展示：

- 验真失败
- 疑似重复
- 红冲/作废
- 证据缺失
- 业务事实不足
- 低置信度
- 高风险
- 暂不能判断

每条异常可以跳转继续处理。

### 5. 正式 API 配置中心

新增路由：`/settings/integrations`。

新增导航：`接口配置`。

配置对象：

- OCR 识别 API
- 发票验真 API
- 凭证接口 API

每个接口字段：

- 接口模式：`模拟` / `正式`
- Base URL
- API Key / Token
- 超时时间
- 重试次数
- 是否启用
- 最后测试结果

功能要求：

- 配置保存到 localStorage。
- 刷新后配置不丢失。
- `测试连接` 使用模拟结果，禁止真实请求外部接口。
- 选择 `正式` 时提示：`当前仅保存配置，不调用真实接口`。
- 侧边栏接口边界区域显示当前模式。
