## 四、Interaction Thesis（动效）

1. **进入序列**：主区 `fade-in-up` 0.28s，结果横幅与步骤详情 `fade-in` 0.18s
2. **Hover**：导航项左侧或移动端顶部 2px 凭证绿指示条；卡片微上移 1px + 边框升级；样本项右移 2px
3. **Focus**：表单输入聚焦时边框过渡到强调色 + 3px 焦点环
4. **当前步骤脉动**：`pulse-soft` 2.4s 慢呼吸提示进行中
5. **降级**：`prefers-reduced-motion` 全局降为 0.01ms

## 五、关键改动点

### 1. 配色系统切换
- 主色从原始墨绿重阴影方案 → 铅墨灰 + 凭证绿 + 风险琥珀的财税工作台方案
- 状态色按业务语义分层：通过为绿、信息为蓝、警示为琥珀、阻断为红
- 强调色聚焦凭证绿，避免页面被单一深蓝/石板色支配

### 2. 阴影克制
- 卡片基类阴影从 `0 18px 48px rgba(34,53,41,0.12)`（重）→ `0 1px 2px rgba(23,33,31,0.04)`（克制）
- 引入三档阴影梯度，按场景使用

### 3. 圆角与边框
- 全局引入 2/4/6/10px 圆角，去除原"零圆角硬切"
- 边框三档：`--c-line` / `--c-line-2` / `--c-line-strong`

### 4. 字重对比强化
- 标题 `font-weight: 600` + `letter-spacing: 0`
- 数字 `font-feature-settings: "tnum" 1`（等宽数字）
- 标签字号细化到 11/12/13/14 四档

### 5. 侧栏与导航
- brand mark 从米白方块 → 凭证绿渐变圆角块（带阴影）
- 导航项 active 由"色块"→"左侧 2px 凭证绿指示条 + 半透底色"，移动端压缩为两列并使用顶部指示条
- 接口边界面板改为半透玻璃感

### 6. 步骤条
- 当前步骤加 `pulse-soft` 慢呼吸 + 凭证绿阴影
- 完成态使用 success-soft 浅绿底
- 步骤号在 done/current 态用反色对比

### 7. 表格与表单
- 表格行 hover 加底色提示
- 表单输入聚焦加 3px 焦点环（`--shadow-focus`）
- 搜索框 `:focus-within` 整体高亮
