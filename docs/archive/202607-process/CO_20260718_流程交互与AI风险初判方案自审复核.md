# CO_20260718_流程交互与AI风险初判方案自审复核

## 自审结论

方案可行，可以指挥 T/IT 开始修改。

## 复核维度

### 1. 是否符合用户问题

通过。

- “映射字段 + 英文”删除：方案只删除 UI 暴露，不破坏内部映射。
- 模板下载：方案提供每项证据的 AI 生成 Markdown 模板和下载链接。
- AI 风险初判无报告：方案在第 6 步人工复核页增加完整初判报告，避免按钮跳步后无反馈。
- 7 步点击跳转：方案增加受控跳转，不允许绕过必要闸门。

### 2. 是否符合产品边界

通过。

- 不接真实文件服务器。
- 不接真实 OCR、验真、凭证接口。
- 不自动过账。
- 不削弱业务问答、证据链和入账风险闸门。

### 3. 是否有误伤风险

低。

- 删除的是 UI 展示文案，不删除 `mappedField` 数据结构。
- 模板下载为新增能力，不影响现有证据勾选。
- AI 风险初判报告为派生展示，不改变现有风险判定函数。
- 步骤跳转通过显式校验，避免用户绕过流程。

### 4. 需要 T/IT 重点防守的问题

1. `NAVIGATE_STEP` 不得修改 `finalStatus`。
2. 点击未来步骤不得绕过必答问题和证据提交。
3. Blob URL 应在组件卸载或重新生成时释放，避免内存泄露。
4. AI 风险报告必须在点击“生成 AI 风险初判”后立即可见。
5. 模板下载按钮不能替代证据上传，只是提供材料填写模板。

### 5. 建议验收优先级

P0：

- 删除业务追问内部字段展示。
- AI 风险初判报告可见。
- 步骤条可点击且不绕过闸门。

P1：

- 证据模板下载。
- 模板内容完整。
- 导航阻断提示清晰。

## 最终判断

该方案范围清晰、技术改动可控、符合当前 MVP 架构，可以进入 T/IT 开发执行。
