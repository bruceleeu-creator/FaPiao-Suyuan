# CO_发票溯源证据链系统任务计划

## 当前目标

把项目保持为可运行的电脑端 Web MVP，并在不影响应用使用的前提下持续补齐“发票录入 -> 业务还原 -> 证据链 -> 风险判断 -> 凭证草稿”的业务闭环。

## 当前状态

| 模块 | 状态 | 说明 |
|---|---|---|
| 工程骨架 | 已完成 | React + Vite + TypeScript，电脑端优先，手机端仅入口占位。 |
| 发票录入 | 已完成 | 支持模拟 OCR、票面确认、税额自动计算和多发票本地流程。 |
| 业务还原 | 已完成 | 支持 AI 业务追问、证据补充、补证模板和流程跳转。 |

## 首期边界

- 一期路线：业务闭环 MVP 优先。
- 产品名称：发票溯源证据链系统。
- 端侧范围：电脑端为主，手机端只保留入口占位。
- 发票范围：八类覆盖，餐饮、住宿、咨询服务三类做深。
- 接口策略：OCR、验真、凭证接口第一版先用模拟数据跑通。
- 入账策略：只生成凭证草稿，不自动过账、不自动申报。
- 风险策略：高风险、低置信度、重大金额、关联交易、证据缺失必须人工确认。
